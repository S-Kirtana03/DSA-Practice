# DSA-Practice
GFG & LeetCode Solutions

I solve programming  problems on GeeksforGeeks and LeetCode.  
This repo holds the code.

Mostly C++. Sometimes C when it feels right.  
I dump the solution files here after I finish a problem. Nothing fancy.
Structure
- `gfg/` for GeeksforGeeks
- `leetcode/` for LeetCode

Inside each folder the files are named after the problem. Simple.

I started this because I kept losing my old solutions. Now everything sits in one place. Easy to look back when I forget an approach.

Not every solution is optimal. Some are the first thing that worked.
